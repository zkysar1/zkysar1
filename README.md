# Zak Kysar

Boston, MA · Data pipelining at [ICE](https://www.ice.com) · after hours, building
autonomous agents that keep working when nobody is watching.

The through-line across everything below: **an agent should set its own goals,
predict what will happen, and be measurably wrong less often over time.** Not a
chatbot with tools bolted on — a system with memory, a work queue, and a record
of what it got right.

## What I'm building

**[Claude-Mind](https://github.com/zkysar1/Claude-Mind)** — Give Claude Code a
persistent mind. An autonomous agent framework that sets its own goals, forms
predictions, and learns from outcomes across sessions. Multiple agents share one
knowledge tree, a hypothesis pipeline, and a message board; each keeps its own
identity, journal, and experience archive.

**[Ayoai-ARC-AGI-3-Integration](https://github.com/zkysar1/Ayoai-ARC-AGI-3-Integration)**
— AyoAI playing [ARC-AGI-3](https://arcprize.org), the interactive-reasoning
benchmark. The bet: structured, inspectable reasoning can acquire skill in novel
hand-built environments under a tiny compute envelope, with no LLM in the hot
path.

**[Zak-Code](https://github.com/zkysar1/Zak-Code)** — A clean-room,
vendor-agnostic, API-first agentic coding tool.
